# 文档展示素材

用于根 README 和 GitHub 首页的静态视觉素材，不参与应用运行。

| 文件                | 来源与用途                                                                                                                    |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `readme-banner.svg` | TEX-66 编写的 SVG 头图，延续产品的深绿、暖白与陶橙品牌色；使用系统字体，无外链、脚本、动画或远程依赖。                        |
| `home-desktop.jpg`  | 2026-10-25 从 `https://riverandraise.app/` 截取的公开首页。只保留产品页面区域，不含账号、房间、令牌、玩家信息或浏览器工具栏。 |

根 README 负责开发入口；`.github/README.md` 负责 GitHub 首页展示。替换素材时检查两个入口的相对路径、图片替代文字、宽屏与窄屏缩放、GitHub 明暗主题下的可读性。首页截图是该日期的界面展示，不作为当前运行状态或发布验收证据。

SVG 可直接在浏览器打开；JPEG 可用图片查看器检查。本目录没有运行时或自动测试，维护时执行文档链接、格式与视觉检查即可。素材随仓库的 Apache-2.0 许可交付，第三方音频许可另见应用的 `THIRD_PARTY_NOTICES.md`。
