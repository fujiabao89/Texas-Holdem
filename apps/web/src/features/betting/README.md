# Betting feature

下注控件、合法动作提示、筹码输入与操作提交（TEX-25）。所有可用按钮、普通 Bet/Raise 范围和 All-in 目标都直接来自服务端投影的 `LegalActions`；`amounts.ts` 仅按前端规格计算展示用快捷候选，并始终夹在服务端区间内。

All-in 永远提交 `{ type: "ALL_IN" }`，以本地两步确认避免误触；普通 Slider/±/精确输入只提交当前 `BET` 或 `RAISE` 的服务端范围。仍聚焦的合法精确草稿在点击提交时必须在同一次交互中作为提交金额，失焦不得吞掉该点击；任何精确草稿变动都会取消既有 All-in 确认。命令回执只控制 pending/重试/反馈，不能更新牌局投影。

TEX-45：牌桌操作面板新增可见标题与“轮到你行动”提示，桌面四列、手机两列；延时按钮独占辅助行。样式由 `poker-table/poker-table.css` 管理，范围、金额草稿、全下二次确认与命令流程不变。

TEX-46：操作区迁到本人 Seat 前方的牌桌下沿并按需显示，[poker-table](../poker-table/README.md) 负责定位与可见性；本目录的按钮集合、`LegalActions` 映射、快捷额公式、金额草稿、全下两步与命令流程均未变。

手机尺寸下主按钮改为三列（延时按钮不再独占整行），金额面板固定为三行——快捷额、金额滑杆与 ±、返回/提交——整体落在牌桌容器预留的高度内，因此打开金额面板不会引入页面滚动，常规下注仍无需数字键盘。手机上展开精确金额输入时，输入框替换快捷额行而不是新增一行，面板高度不变；“返回操作”按钮只在手机出现，用于从金额面板退回主操作行。
