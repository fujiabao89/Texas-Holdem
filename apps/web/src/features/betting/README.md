# Betting feature

下注控件、合法动作提示、筹码输入与操作提交（TEX-25）。所有可用按钮、普通 Bet/Raise 范围和 All-in 目标都直接来自服务端投影的 `LegalActions`；`amounts.ts` 仅按前端规格计算展示用快捷候选，并始终夹在服务端区间内。

All-in 永远提交 `{ type: "ALL_IN" }`，以本地两步确认避免误触；普通 Slider/±/精确输入只提交当前 `BET` 或 `RAISE` 的服务端范围。仍聚焦的合法精确草稿在点击提交时必须在同一次交互中作为提交金额，失焦不得吞掉该点击。命令回执只控制 pending/重试/反馈，不能更新牌局投影。
