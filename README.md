# Texas Hold'em

项目根目录。这里仅保存仓库级说明、工程约定和配置入口；当前阶段不包含可执行业务代码。

目录约定见各子目录的 `README.md`；工程文档入口见 [docs/README.md](./docs/README.md)，分支与 Linear 任务命名规则见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

多 Agent 协作以 [AGENTS.md](./AGENTS.md) 为共同契约；角色专属入口分别为 [CLAUDE.md](./CLAUDE.md)、[TRAE.md](./TRAE.md) 与 [CODEX.md](./CODEX.md)。

本项目采用 [Apache-2.0](./LICENSE) 许可证。工作任务只在 Linear 中管理；安全问题请遵循 [SECURITY.md](./SECURITY.md)。
