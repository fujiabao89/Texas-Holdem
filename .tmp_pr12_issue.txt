### P1 — `Deck.toArray()` 泄漏内部 Card 引用，可破坏牌堆不变量

`packages/poker-engine/src/cards/deck.ts` Line 65 只复制了数组，不复制其中的 `Card` 对象。`Card` 的 `readonly` 只在 TypeScript 类型层生效。运行时调用方可以修改返回 Card，直接污染 `Deck.cards`。

可复现：

```ts
const deck = new Deck();
const snapshot = deck.toArray();

(snapshot[0] as { rank: number }).rank = 14;
// 初始第一张为 2s。此时 Deck 内同时存在两个 As，且不再存在 2s。
```

这违反了规格中的卡牌唯一性和牌堆守恒不变量。后续 `draw()` 会从已损坏的牌堆发牌。

请使 Card 在运行时不可变，或让 `toArray()` 返回每张 Card 的独立副本。请添加测试，修改 `toArray()` 返回值后仍验证牌堆保持 52 张唯一标准牌。

### P2 — 循环无效输入不会抛出声明的 `InvalidCardError`

`packages/poker-engine/src/cards/hand-evaluator.ts` Line 67 在构造 `InvalidCardError` 时执行 `JSON.stringify(card)`。如果无效 Card 是循环对象，`JSON.stringify` 会先抛出原生 `TypeError`。`evaluateHand()` 因此不满足“无效 Card 抛明确错误”的公开契约。

请使用不会抛错的错误描述，或在序列化失败时使用固定占位文本。请添加循环对象输入测试，并断言抛出 `InvalidCardError`。
